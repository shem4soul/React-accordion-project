# React Accordion Project

A simple and interactive FAQ Accordion built with React. This project demonstrates the use of React functional components, props, state management with the `useState` Hook, event handling, and conditional rendering.

## 🚀 Live Demo

🔗 https://react-accordion-project-g3gwlbrhk-shittu-emmanuels-projects.vercel.app/

## 📂 Repository

🔗 https://github.com/shem4soul/React-accordion-project

## ✨ Features

- Interactive accordion component
- Expand and collapse FAQ items
- React Hooks (`useState`)
- Conditional rendering
- Reusable components
- Responsive UI

## 🛠️ Technologies

- React
- JavaScript (ES6+)
- CSS3
- HTML5

## Installation

Clone the repository:

```bash
git clone https://github.com/shem4soul/React-accordion-project.git
```

Go into the project folder:

```bash
cd React-accordion-project
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm start
```

Open your browser at:

```
http://localhost:3000
```
